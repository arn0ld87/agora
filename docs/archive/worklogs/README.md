# Arbeitsprotokoll-Archiv

Dieses Verzeichnis enthält historische Arbeitsprotokolle, Slice-Logs und Agenten-Laufzettel.

Sie sind absichtlich archiviert:

- Sie dokumentieren frühere Entscheidungen und Debugging-Schritte.
- Sie sind nicht der primäre Einstieg in das Projekt.
- Aktuelle Entwickler-Doku liegt unter `docs/`.
- Aktueller Status liegt in `docs/status.md`.
- Der operative Plan liegt in `PLAN.md`.

Neue Doku mit dauerhaftem Wert gehört nicht hierher, sondern in die passende Datei unter `docs/`. Neue rein historische Laufzettel können hier abgelegt werden, wenn sie für Nachvollziehbarkeit gebraucht werden.
