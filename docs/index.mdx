# 🏛️ Agora

**Documents → Knowledge Graph → Personas → Simulation → auditierbarer Report**

Agora ist eine hybride Multi-Agenten-Resonanz-Simulationsplattform (Flask-Backend, Vue-3-Frontend, Neo4j-Knowledge-Graph, lokale LLMs via Ollama). Sie generiert **auditable Szenarien, mögliche Einwände, Konfliktlinien und Datenlücken** — für Stakeholder-Analysen, Zielgruppen und komplexe Entscheidungen.

> [!IMPORTANT]
> **Agora sagt menschliches Verhalten nicht voraus.** Die Plattform erzeugt nachvollziehbare Szenarien und weist auf Datenlücken hin. Simulationsergebnisse ersetzen keine Interviews, Usertests oder empirische Forschung.

## Diese Seite ist agentenfähig

Diese Doku stellt ihre Inhalte auch Maschinen bereit:

- **`/llms.txt`** und **`/llms-full.txt`** — kompakter und vollständiger Index für LLMs
- **`/mcp`** — MCP-Server (Streamable HTTP) mit den Tools `search_docs`, `get_page`, `list_pages`, `get_navigation`
- **JSON-API** — `/api/docs/pages.json`, `/api/docs/navigation.json`, `/api/docs/search?q=…`

Zum Verbinden aus Claude Code:

```bash
claude mcp add --transport http agora-docs http://localhost:4321/mcp
```
